# Source notes

One file per work, named by its key in `../refs.bib`, with id `src/<key>` and type `source`.
Excerpts go in the same file under `## Excerpts`, each with its exact location, or as separate
`excerpt` entries when other entries need to link to them. Created when a work is actually read for
an investigation, not in advance.

```
---
id: src/stroud1968
type: source
title: Stroud, Transcendental Arguments
status: noted
cites: [stroud1968]
---
What the work argues, in a few sentences, and why it matters here.

## Excerpts
- p. N: "quoted passage" (verified: text)
```

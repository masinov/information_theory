The core is a schema: it states what any dependence must satisfy to count as registration, and each domain supplies the dependence. It is to be shown non-empty by at least two worked realizations, one of them not physical.

## Reasons
Content: characterized only by its properties, and with C-local denying that any description fixes whether it holds, the dependence in C cannot by itself tell registration from correspondence (F-trivial); read as a schema, the core does not need to, since the telling is done in each domain. Method: this is what Dec-trunk already did for the analyses of C, said of the core as a whole. Found in Claude's review of 2026-11-10; the author accepted the correction ("I accept all your corrections and the phases proposed").

If F is everything, there is nothing beside it, and it is identified only through the differences within it.

## Origin
The author raised the case: "Even if we assumed the something is the totality, to take the totality we need to separate it from the absence, which in turn is a differentiation." Claude pointed out that absence is not an actual term, so that a difference between the totality and its absence is a difference from an alternative, which Dec-readingA does not admit; and put two readings. The author: "Reading 1 is correct."

## Does not establish
That the totality cannot be set against its absence by other means; only that the core does not use that difference.

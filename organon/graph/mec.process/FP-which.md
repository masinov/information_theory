The core's gap F-which reappears unchanged in Br-actual: without pure potentials, registration of which way F is must still be rebuilt from contrasts between actual occasions. Br-eternal closes the gap only by giving up Reading A.

## Proposal (2026-10-24)
mec/Which-position gives Br-actual what it lacked: definiteness as position among actual occasions, relative to the variety they actually have. If it is adopted, this gap closes by the same restriction as F-which. Br-eternal rejects the restriction, since in Whitehead's own scheme an occasion is definite against pure potentials, not only against what is actual. FP-math is unaffected: necessary contrasts are not contrasts between actual terms (see mec/Q5).

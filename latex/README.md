# Typesetting the monograph (LaTeX)

`main.tex` builds *Registered Information over Contrast Domains* from the Markdown sources in `../monograph/`.
Engine: **LuaLaTeX** (fonts: Libertinus), bibliography: **biblatex + biber**, class: **scrbook** (6.5 × 9.5 in).

## Build

```sh
sh tools/build.sh        # converts Markdown -> TeX, then lualatex + biber + lualatex x2 -> ri.pdf
python tools/overfull.py 8   # worst overfull boxes with file/line
python tools/verify.py       # prose-fidelity check of the PDF against the Markdown (see caveat below)
```

Requires MiKTeX/TeX Live, pandoc >= 3, Python 3. (`build.sh` adds the Windows install paths of MiKTeX and pandoc to `PATH`.)
The output file is `ri.pdf` (`-jobname=ri`, so an open viewer on another PDF never blocks the build).

## Layout

| path | role |
|---|---|
| `main.tex`, `preamble.tex` | document, packages, theorem styles, headers |
| `frontmatter/` | title page, abstract, preface (hand-written) |
| `parts/I.tex … XI.tex` | **generated** from `monograph/registered-information-*.md` |
| `appendices/B.tex, C.tex, D2.tex` | **generated** (D.8–D.13); `appendices/D.tex` inputs `manual/D1-7.tex` then `D2.tex` |
| `manual/A.tex`, `manual/D1-7.tex` | **hand-typeset**: the Markdown for Appendix A and D.1–D.7 writes its mathematics in plain text |
| `refs.bib` | curated bibliography (first generated by `md2tex.py --bib`, now edited by hand) |
| `tools/md2tex.py` | pre-processing, citation conversion, pandoc driver, editorial edits (`EDITS`) |
| `tools/stmt.lua` | headings, numbered statements, proofs, table widths |
| `tools/mathfix.lua` | stacks over-wide display equations |
| `tools/xref.lua` | turns "Theorem 6.5", "§16.1" into hyperlinks |

Generated files are overwritten on every build: edit the Markdown (or `EDITS` in `md2tex.py`), not `parts/*.tex`.
If Appendix A or D.1–D.7 change in the Markdown, port the change to `manual/`.

## Conventions kept from the Markdown

* Sections run continuously §0–§89 across parts; subsections are `§n.m`. Statement numbers are taken verbatim from the source
  (`Theorem 19.1`, `Proposition 14.4′`, `Worked example E`), and every statement is a hyperlink target `stmt:<number>`.
* Citations `[Author Year; …]` become `\autocite` / `\textcite` keys; `tools/md2tex.py` reports groups it cannot resolve.
* The internal-review material (banner, "References added in Part …", links to `review/`) is removed or reworded in `EDITS`;
  the Markdown sources are untouched.

## Caveat on `verify.py`

`pdftotext` scrambles math glyphs, so statements dense with formulas are reported as false positives. Treat its output as a
pointer to pages worth looking at, not as a proof of equality.

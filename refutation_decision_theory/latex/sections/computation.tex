\section{Optimal agents and computable optimisation}\label{sec:computation}

This section asks what changes when the decision theory of Theorem~\ref{thm:universal} must be a
single function of descriptions, and then a single algorithm. For functions, nothing changes: an
optimal function exists on both admissible classes considered, fixed copies of arbitrary programs
included. For algorithms, with a fixed substitution semantics and a termination promise, nothing
changes either: one algorithm is optimal everywhere. Obstructions appear once the algorithm must halt on every input or
the class admits exact comparisons among computable reals, and none of them concerns counterfactual
inference. Section~\ref{sec:degrees} measures them exactly.

\subsection{Optimal decision functions}

Throughout this section and the next, the semantics is $O_{\mathrm{oracle}}$ with embedded programs
held fixed: every designated call is answered by the evaluated agent, and every other program in the
environment runs as an ordinary computation, its running time counting as part of the environment's
execution.

\begin{definition}[Admissible classes]\label{def:promise}
$\mathcal P_{\mathbb Q}$ is the class of program environments $E$ such that $E^\pi$ halts and returns an
exact rational value $V_E(\pi)$ for every $\pi\in\Pol_E$. $\mathcal P_{\mathrm{as}}$ is the class of
probabilistic program environments, branching with exact rational probabilities and returning
terminal rewards that are rationals in $[0,1]$, such that $E^\pi$ terminates with probability~$1$ for
every $\pi\in\Pol_E$; then $V_E(\pi)$ is the expected reward.
\end{definition}

Both definitions use table oracles, so the admissibility of an environment is not defined in terms
of whichever optimiser is eventually constructed. In $\mathcal P_{\mathrm{as}}$ the reward bound is
enforced by the language, so that it holds also on programs that fail the termination promise, and
almost-sure termination is required of the whole execution, embedded computations included; nothing
is required of embedded programs on inputs the environment never supplies, nor of executions of
probability zero.

\begin{definition}[Decision functions]\label{def:decfn}
A \emph{decision function} is a total function $T$, not necessarily computable, from descriptions to
actions with $T(x)\in A(x)$. On a class $\cls$ of admissible environments, $T$ is \emph{optimal} if
$U(E,T)\ge U(E,A)$ for every $E\in\cls$ and every decision function $A$.
\end{definition}

Under $O_{\mathrm{oracle}}$ the evaluated agent enters an execution only through its answers on owned
queries, so $U(E,A)=V_E(\pi^A_E)$ with $\pi^A_E(h)=A(q(E,h))$. Every table $\pi\in\Pol_E$ extends to a
globally total computable agent, hence
\begin{equation}\label{eq:maxtable}
  \max_A U(E,A)=\max_{\pi\in\Pol_E}V_E(\pi),
\end{equation}
whether $A$ ranges over decision functions or over computable agents. Optimality is therefore a
property of a function, and the questions of this section and the next concern how hard that
function is to compute.

\begin{theorem}[Optimal decision functions exist]\label{thm:existence}
On $\mathcal P_{\mathbb Q}$ and on $\mathcal P_{\mathrm{as}}$ there is an optimal decision function,
and it can be chosen to return a fixed default action on every description that is not an owned query
of an admissible environment.
\end{theorem}

\begin{proof}
Fix an effective order on each finite policy space, and for admissible $E$ let $\pi^*_E$ be the first
maximiser of $V_E$, which exists because $\Pol_E$ is finite and every value is defined (in
$\mathcal P_{\mathrm{as}}$, finite because rewards are bounded). Put $T^*(q(E,h))=\pi^*_E(h)$ for
admissible $E$, and the default elsewhere. Since owned-query namespaces are disjoint, no description
receives prescriptions from two environments, so $T^*$ is well defined, and
$U(E,T^*)=V_E(\pi^*_E)=\max_A U(E,A)$ by \eqref{eq:maxtable}.
\end{proof}

The definition is explicit and uses no choice principle. It covers environments containing fixed
copies of arbitrary programs, including programs that compute candidate theories: such a copy is a
fixed feature of $V_E$, whatever it computes. Requiring each problem to fix how the world responds to
every policy therefore does not exclude problems that refer to a particular theory; it excludes
dependence on the \emph{evaluated} agent other than through its owned queries. The hard-coded
counterpart of Remark~\ref{rem:skalse}, the family $D_b$, needed a fixed point that does not exist;
the program counterpart below needs none.

Disjoint ownership is sufficient for existence, not necessary. The exact condition is compatibility:
a class $\cls$ has an optimal decision function iff
\[
  \textstyle\bigcap_{E\in\cls}\{T:\pi^T_E\in\argmax V_E\}\neq\varnothing .
\]
Without ownership the condition fails at once.

\begin{proposition}[Foreign queries]\label{prop:foreign}
There are two terminating environments such that no decision function is optimal on both under
$O_{\mathrm{oracle}}$.
\end{proposition}

\begin{proof}
Fix a binary query $q$ distinct from both environments' own descriptions, and let $E_0$ pay
$\one[A(q)=0]$ and $E_1$ pay $\one[A(q)=1]$. Each has optimal value $1$, attained by a constant agent,
and no decision function attains $1$ in both.
\end{proof}

This is a cross-problem consistency contradiction requiring neither self-reference nor
undecidability, and it eliminates optimal functions of every Turing degree. It is excluded by
$\cls_{\mathrm{self}}$ with disjoint namespaces, and it disappears under $O_{\mathrm{const}}$, which
freezes the foreign response.

\subsection{A uniform optimiser}

\begin{theorem}[Uniform optimisation on the promise class]\label{thm:promiseopt}
There is a computable agent that is promise-total on $\mathcal P_{\mathbb Q}$ and optimal under
$O_{\mathrm{oracle}}$ on every $E\in\mathcal P_{\mathbb Q}$.
\end{theorem}

\begin{proof}
On input $q(E,h)$, let $P$ recover $E$ and its finite policy space, run $E^\pi$ for every
$\pi\in\Pol_E$, select the first maximiser $\pi^*_E$ of $V_E$ in a fixed effective order, and return
$\pi^*_E(h)$. Every simulation halts by the promise, there are finitely many, and exact rational
comparison terminates. All owned queries of $E$ recover the same environment and use the same
tie-breaking, so the answers form the single policy $\pi^*_E$, and $P$ agrees with $T^*$ of
Theorem~\ref{thm:existence} on every admissible environment.
\end{proof}

$P$ never asks its live self what it would do during a simulated execution; it supplies table
answers instead. This is Theorem~\ref{thm:universal} made uniform: the lookup table is replaced by
an algorithm, and no knowledge of which parts of $E$ are predictors is needed, because oracle
substitution designates them. By Proposition~\ref{prop:progmatrix} the theorem maximises the
diagonal of $M_E$.

An explicit finite policy header is sufficient for the argument but not necessary. A finitely
branching oracle machine that halts for \emph{every} total oracle has a finite tree of consistent
oracle answers, since otherwise Kőnig's lemma \autocite{konig1927} gives an infinite path, whose
answers extend to a total oracle on which the machine runs forever; exhaustive exploration of the
tree then yields a finite optimisation problem. Halting against every \emph{computable} oracle does
not justify this compactness argument, since an infinite computable tree can lack a computable
infinite path.

Dependence of termination on the oracle is harmless as long as every policy terminates. The theorem
fails when some alternatives are undefined: if action $0$ returns $0$ and action $1$ simulates
machine $e$ and returns $1$ if it halts, the environment lies outside $\mathcal P_{\mathbb Q}$ unless
$e$ halts. Adding the convention that divergence pays $-1$ would make an exact optimiser choose $1$
exactly when $e$ halts, and so decide the halting problem. The obstruction then comes from the
added divergence semantics, not from the finite-policy argument.

\subsection{The fixed-copy diagonal}

The optimiser $P$ halts only on the promise. Requiring an agent to halt on every input brings in a
diagonal that again involves no counterfactual subtlety.

\begin{theorem}[The fixed-copy diagonal]\label{thm:fixedcopy}
No globally total computable agent is optimal on $\mathcal P_{\mathbb Q}$, even on its deterministic,
binary environments with payoffs in $\{0,1\}$ that consult the evaluated agent only on their own
description.
\end{theorem}

\begin{proof}
Fix a globally total computable $T$, and construct an environment $E_T$ containing the fixed algorithm
$g_0=T$. With $d=d(E_T)$, it computes $c=g_0(d)$, receives the evaluated agent's action $a$ at the
port, and pays $\one[a\neq c]$. The algorithm $g_0$ does not change when the evaluated agent changes,
so $U(E_T,A)=\one[A(d)\ne T(d)]$. Since $T$ is globally total, $g_0(d)$ halts, so $E_T$ terminates
under either action and lies in $\mathcal P_{\mathbb Q}$. $T$ receives $0$, and the agent taking
$1-c$ at $d$ receives $1$.
\end{proof}

In a programming formalism with no built-in parameter for the environment's own description,
Kleene's second recursion theorem \autocite{kleene1938} supplies the self-reference; see
\textcite{moschovakis2010} for a modern statement and proof. It produces a program with a specified
behaviour involving its own index; it does not prove that the behaviour terminates, and global
totality is what supplies termination. The construction is uniform in an index of $T$. The proof
holds under $O_{\mathrm{const}}$, and under $O_{\mathrm{oracle}}$ whenever $g_0$ is an ordinary fixed
program rather than a designated oracle call. The transparent-and-opaque-box construction of
\textcite{skalse2021} is the same mechanism with different payoffs, and a footnote of
\textcite[§9, n.~15]{yudkowskysoares2017} already discusses an environment that punishes agreement with a
fixed copy of a particular program. The proof that AIXI is not computable
\autocite[Thm.~14]{leikehutter2015aixi} builds an environment that simulates a given computable policy
and acts against it, the same diagonal in reinforcement learning; informal fixed-simulation problems
appear in \textcite{drnickbone2012}.

Remark~\ref{rem:skalse} found that construction ill defined in the model of
Section~\ref{sec:model}, and the reason for the difference is the following. There a problem was a finite object whose
data included the constant's output, so the construction required a problem $D_b$ with $b=T(D_b)$,
and an ex-ante optimiser has no such fixed point. Here the description of $E_T$ encodes a
computation involving $T$ without supplying its result, and no fixed point is needed: whatever $T$
outputs on $d(E_T)$, the copy outputs the same. Once that output $c$ is known, the environment is
the ordinary one-shot problem with payoffs $\one[a\ne c]$, and its maximiser is $1-c$. The agent
cannot uniformly select it while remaining globally total, because finding $c$ means running $T$ on
the very description it is reading.

The diagonal cannot be built against an optimal agent, and for the promise-total optimiser this can
be proved rather than suggested.

\begin{proposition}[Escape of the promise optimiser]\label{prop:escape}
Let $E_P$ be the diagonal environment of Theorem~\ref{thm:fixedcopy} built from the optimiser $P$ of
Theorem~\ref{thm:promiseopt}. Then $P(d(E_P))$ diverges, so $E_P\notin\mathcal P_{\mathbb Q}$.
\end{proposition}

\begin{proof}
Suppose $P(d(E_P))$ halted with output $b$. Then $E_P$ would halt under both actions with payoffs in
$\{0,1\}$, so it would be admissible, and $P$, optimal on admissible environments, would output the
maximiser $1-b$, not $b$.
\end{proof}

The escape depends on the evaluation convention. Assigning a payoff to divergence and admitting
$E_P$ changes both the class and the optimisation problem, as the halting example above shows.

A non-computable optimal function escapes in a different way. No embedded program computes it
globally, but a computable program can agree with it on any finite set of inputs, and
non-computability does not forbid such agreement. What optimality forbids is agreement at one
particular input. For a fixed program $p$, let the \emph{anti-prediction environment} $E_p$ compute
$c=p(d(E_p))$, read the action at its port, and pay $\one[a\ne c]$.

\begin{proposition}[Anti-prediction]\label{prop:antipred}
If $T$ is optimal on $\mathcal P_{\mathbb Q}$ and $p(d(E_p))$ halts with an action, then
$T(d(E_p))=1-p(d(E_p))$. In particular, no fixed program is accurate for an optimal decision function
on the input of its own anti-prediction environment.
\end{proposition}

\begin{proof}
If $p(d(E_p))$ halts, $E_p$ is admissible with optimal value $1$, attained only by the action
$1-p(d(E_p))$.
\end{proof}

Hard-coding does not evade this. An environment that hard-codes a bit $k$ as its prediction is the
anti-prediction environment of the constant program $k$, and the proposition forces $T(d)=1-k$ on its
description $d$; for the two environments $E_0,E_1$ with constant predictions $0$ and $1$, an optimal
function satisfies $T(d(E_0))=1$ and $T(d(E_1))=0$, so neither satisfies $k=T(d(E_k))$. The
observation that inserting the bit changes the description is not by itself the argument; the
argument is that the required self-consistency fails for every optimal function. The immunity
belongs to optimal functions, not to non-computable ones (Proposition~\ref{prop:unfair}).

A last baseline is the program form of Death in Damascus.

\begin{proposition}[Self-prediction held fixed]\label{prop:doublecall}
Let an oracle environment call the agent twice on $d$, treating one answer as a prediction $p$ and the
other as the action $a$, and pay $\one[a\neq p]$. Under $O_{\mathrm{oracle}}$ every agent receives $0$
and every agent is optimal. Under $O_{\mathrm{const}}$ every agent has an improving deviation.
\end{proposition}

\begin{proof}
Coherent substitution answers both calls alike. An intervention changing only the action, with the
prediction frozen at the reference agent's answer $p$, earns $1$ with $a=1-p$.
\end{proof}

By Proposition~\ref{prop:progmatrix}, this is the matrix
$\bigl(\begin{smallmatrix}0&1\\1&0\end{smallmatrix}\bigr)$, in which no diagonal entry is maximal in
its row; it is Proposition~\ref{prop:did} again, a ratifiability obstruction and not a computability
result. Whether the prediction is linked to the agent, as under $O_{\mathrm{oracle}}$, or fixed, as
under $O_{\mathrm{const}}$, is exactly what separates it from the fixed-copy diagonal. If the embedded
copy of Theorem~\ref{thm:fixedcopy} is declared linked, replacing $T$ by $A$ changes both
occurrences, the payoff becomes $\one[A(d)\ne A(d)]=0$, and every agent is optimal there. Actual
behaviour cannot settle the declaration: a fixed program computing $0$ and a linked call to an agent
that outputs $0$ agree on the actual execution and differ under replacement.

\subsection{Exact selection}

The following result avoids every baseline: there are no predictors, no copies of the agent, no
foreign queries, and the agent need halt only on valid inputs.

\begin{theorem}[No computable exact optimiser]\label{thm:exactsel}
No promise-total computable agent is optimal on $\mathcal P_{\mathrm{as}}$, even on its binary-choice
environments whose realised payoffs lie in $\{0,1\}$, that consult the agent only at the action port
on their own description, whose expected values are uniformly computable, and whose expected running
time is finite.
\end{theorem}

\begin{proof}
Let $(\varphi_e)$ be an effective enumeration of the partial computable functions, and let
$K_b=\{e:\varphi_e(e)\text{ halts with output }b\}$ for $b\in\{0,1\}$. The environment $E_e$ receives
the action $a\in\{0,1\}$, draws $N\in\mathbb N$ with $\Pr(N=n)=2^{-n-1}$, simulates $\varphi_e(e)$ for $N$
steps, and pays $1$ if the simulation halts within them with output $a$, and $0$ otherwise. Every
simulation is bounded, $E_e$ terminates almost surely, and its expected running time is finite. If
$e\in K_b$ with halting time $t$, then $V_e(b)=\Pr(N\ge t)=2^{-t}>0$ and $V_e(1-b)=0$; if neither
output occurs, both values are $0$.

Suppose a promise-total computable exact optimiser $T$ existed. Then $f(e)=T(d(E_e))$ is a total
computable function with $f(e)=b$ whenever $e\in K_b$. Let $e$ be an index of the total program
$x\mapsto1-f(x)$. Then $\varphi_e(e)=1-f(e)$, so $e\in K_{1-f(e)}$, and the condition requires
$f(e)=1-f(e)$.
\end{proof}

The proof is the recursive inseparability of $K_0$ and $K_1$ \autocite[Thm.~II.2.5]{odifreddi1989}. What
fails is \emph{exact selection}, not the approximation of expected values: after $n$ simulation steps
the unresolved part of each expectation is at most $2^{-n}$, so the values are uniformly computable
reals with an explicit error bound. What cannot be computed uniformly is which action belongs to the
exact argmax when arbitrarily small advantages and genuine ties are both admitted. The obstruction
disappears as soon as one of the two is excluded.

\begin{proposition}[Positive replacements]\label{prop:approxopt}
On a class of environments with finite policy spaces and uniformly computable values, there are
promise-total agents that are
\begin{enumerate}[label=(\roman*)]
  \item $\varepsilon$-optimal everywhere, for any fixed rational $\varepsilon>0$;
  \item exactly optimal on every environment with a unique maximising policy;
  \item exactly optimal on every environment whose values are exact rationals.
\end{enumerate}
\end{proposition}

\begin{proof}
(i) Approximate every value within $\varepsilon/3$ and maximise the approximations. (ii) Refine
enclosing intervals until one policy's lower bound exceeds every other policy's upper bound, which
happens in finite time when the maximiser is unique. (iii) is Theorem~\ref{thm:promiseopt}.
\end{proof}

Theorem~\ref{thm:exactsel} is therefore a true and non-trivial version of the thesis that no
computable rule is optimal on all fair problems, on an especially fair class. Its obstruction is
classical recursion theory, not a conflict among decision theories. Together with
Theorem~\ref{thm:existence} it separates the two things the thesis ran together: optimal choice,
problem by problem, is always possible, and an optimal \emph{program} is not.
